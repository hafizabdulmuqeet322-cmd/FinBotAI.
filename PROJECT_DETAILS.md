## 🧠 Advanced AI Capabilities
### 1. Global Multi-Currency Intelligence
*   **Automatic Normalization**: Seamlessly converts international transactions (e.g., travel expenses in EUR) into your base currency (e.g., PKR) using real-time equivalent rates.
*   **Unified Reporting**: "You spent **$50 USD** last month, which impacts your **14,000 PKR** budget."

### 2. Smart Recommendations Engine
*   **50/30/20 Analysis**: Automatically detects if your Needs (50%), Wants (30%), or Savings (20%) are off-balance.
*   **Category-Specific Insights**: "You spent **20% more on Food** than usual. Reduce dining out by 15% to save **5,000 PKR**."
*   **Risk Detection**: Instant alerts for spending anomalies or projected debt.

### 3. Visual Decision Support
*   **Predictive Dashboard**: Visualizes *Next Month’s* spending before it happens.
*   **Financial Health Confidence**: A live 0-100 score quantifying your financial stability.
*   **Trend Heatmaps**: Identifies high-spending days and seasonal patterns.

## 🛠️ Technical Engineering & Architecture
*   **Frontend**: React + Vite + Recharts (High-performance Interactive UI).
*   **Backend**: FastAPI (Python) for asynchronous, high-concurrency API handling.
*   **AI Core**: Scikit-Learn (RandomForest) + Pandas + NumPy for real-time inference.
*   **Database**: SQLite (Dev) / PostgreSQL (Prod) with SQLAlchemy ORM.
*   **Security**: JWT Authentication + Bcrypt Hashing + Data Isolation.
